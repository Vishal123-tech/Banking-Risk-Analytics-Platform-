# Stress Testing Framework

The dashboard applies illustrative PD and LGD multipliers to the selected base ECL:

| Scenario | PD multiplier | LGD multiplier |
| --- | ---: | ---: |
| Base | 1.00× | 1.00× |
| Mild Recession | 1.25× | 1.10× |
| Severe Recession | 1.50× | 1.30× |
| COVID Shock | 1.80× | 1.20× |
| 2008 Crisis | 2.00× | 1.50× |

## Formula used in the demo

Stress ECL = Base ECL × PD multiplier × LGD multiplier

## Interpretation

These scenarios are illustrative sensitivity assumptions for a portfolio project. They are not calibrated macroeconomic scenarios, regulatory capital results, or probability-weighted IFRS 9 forecasts.
